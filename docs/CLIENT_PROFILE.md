# Selected Client Profile — Airbnb

## Positioning

**Airbnb** is the selected reference client profile for this portfolio exercise: a global accommodation marketplace that benefits from clear, trustworthy short-form property visuals. This selection is for planning only. Airbnb is not a client, sponsor, partner, listing owner, or approver of this project.

## Asset-use boundary

No Airbnb-owned photographs, videos, listings, logos, trademarks, copy, or other brand assets have been supplied in this repository. They must not be copied from Airbnb websites or used in the portfolio without explicit written permission from the rights holder.

The Atria House demonstration will instead use one independently licensed 3D property asset, selected only after the asset audit verifies commercial derivative rights and required attribution. The resulting website will retain the disclosure: `Independent demonstration created from a licensed 3D asset. Not an active property listing.`

## Client-fit hypothesis

The reusable workflow is designed to help accommodation and property-marketing teams turn approved property assets into accurate, platform-ready video. It does not promise booking, revenue, occupancy, or platform performance results.
