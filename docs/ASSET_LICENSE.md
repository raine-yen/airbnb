## Publication rule

No property render, thumbnail, social asset, or public demonstration video may be published until all of the following are recorded from the actual source material:

1. Exact model title.
2. Creator's exact displayed name.
3. Original source URL.
4. Exact license and license text.
5. Whether commercial and derivative use are explicitly permitted.
6. The exact attribution wording required by the license.

Do not infer Creative Commons permissions from a file name, project brief, or search result. Preserve a copy of the supplied license or README in `source-assets/licenses/`.
