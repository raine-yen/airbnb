# Atria House Property Visualization

## Mission

Create a truthful demonstration of cinematic property-marketing video work for apartment and rental portfolios. The demo is fictional and must never be presented as an active listing, client commission, or performance guarantee.

## Project rules

- Use pnpm for the website when it is installed; do not commit credentials, private client assets, downloaded archives, or render caches.
- Run `pnpm quality` before any release claim. Run the documented scene, video, and browser checks appropriate to the output.
- Inspect every source asset and record its exact source, creator, and license before publishing render output. Preserve originals and edit copies only.
- Block public property-render release when the source license is missing, conflicting, noncommercial, or otherwise unclear.
- Do not fabricate approvals, client relationships, listings, features, results, testimonials, attribution, or quality scores.
- A release requires all automatic gates, no known critical defect, independent review records, and an evidence-backed score. Never call incomplete work complete.
- Use a maximum of ten complete review passes. At the limit, report the strongest result and all remaining defects honestly.

## Required final outputs

Vertical and horizontal video exports, website source and successful build, disclosure and attribution, complete quality documentation, business drafts, repeatable scripts, and a final quality report.
